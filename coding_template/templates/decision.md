# Decision Log

> 目的：记录产品、技术、实现和验证中的重要取舍。每个影响长期维护、验收标准或实现边界的决定都应写入本文件。

## 决策条目格式

### DEC-[YYYYMMDD]-[编号]：[决策标题]

- 日期：[YYYY-MM-DD]
- 状态：[Proposed / Accepted / Superseded / Rejected]
- 决策问题：[要解决的问题]
- 选项：
  - A：[选项与影响]
  - B：[选项与影响]
  - C：[选项与影响，如无则删除]
- 选择：[最终选择]
- 理由：[为什么选择它]
- 影响范围：[涉及的 spec / 页面 / 接口 / 数据 / 代码目录]
- 回滚条件：[什么情况下需要撤销或重选]
- 相关文件：[路径]
